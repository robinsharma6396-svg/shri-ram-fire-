# Shri Ram Fire Safety website

A responsive static company website built with HTML, CSS and JavaScript.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Keep the `assets` folder beside `index.html`.

## Publish free with GitHub Pages
1. Create/sign in to a free GitHub account at https://github.com/.
2. Create a **public** repository named `shri-ram-fire-safety`.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the complete `assets` folder to the repository root.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. Your free address will look like `https://YOUR-USERNAME.github.io/shri-ram-fire-safety/`.

## Important setup before publishing
- Confirm that `+91 70535 05054` is the company's WhatsApp-enabled number. If not, replace `917053505054` in the two WhatsApp links in `index.html` with the correct country-code + number (digits only).
- The quotation form uses `mailto:`. It opens the visitor's email app; it does not save submissions to a server. A server-backed form requires a form service or backend.
- Replace the project gallery placeholders with real, approved company project photos. Add the photos to `assets` and update the relevant placeholder blocks in `index.html`.
- Product illustrations are stylized placeholders, not real product photographs or technical specifications.
- Verify phone numbers, address, credentials, client permissions, and all company claims before going live.
- The company profile says established 1 April 2008 and describes 15+ years' experience; the page uses the profile's wording. Update the displayed experience figure when desired.

## Free hosting
GitHub Pages supports static HTML/CSS/JS sites at no hosting cost. A custom `.com` domain is optional and paid separately.
